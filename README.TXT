# 👨‍🎓 Sistema de Cadastro de Alunos

Um sistema desenvolvido para gerenciar o registro de estudantes, permitindo realizar operações essenciais como cadastro, consulta, atualização e remoção de dados acadêmicos de forma eficiente.

---

## ✨ Funcionalidades

- **Cadastro de Alunos:** Adição de novos estudantes com informações detalhadas (nome, ID/matrícula, curso, notas, etc.).
- **Consulta / Listagem:** Visualização de todos os alunos cadastrados ou busca por registros específicos.
- **Atualização de Dados:** Modificação de informações de estudantes já existentes.
- **Remoção:** Exclusão de registros do sistema.
